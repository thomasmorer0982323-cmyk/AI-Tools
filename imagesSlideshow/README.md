# AICat - AI Tools Website

Een overzicht van verschillende AI-tools en engines.

## Lokale ontwikkeling
Open `index.html` in je browser om de site lokaal te bekijken.

## Deployment naar GitHub Pages
1. Ga naar je repository op GitHub: https://github.com/Gert-314/AICat
2. Klik op **Settings** (tandwiel icoon)
3. Scroll naar beneden naar **Pages** in de linker zijbalk
4. Onder **Source**, selecteer **Deploy from a branch**
5. Kies **main** als branch en **/(root)** als folder
6. Klik op **Save**

De site zal beschikbaar zijn op: https://gert-314.github.io/AICat/

## Automatische updates
Elke push naar de `main` branch zal automatisch de website updaten via GitHub Pages.
